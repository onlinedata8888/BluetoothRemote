# Remote5 2 - "Mobile Style" page upgrades

1. **Naam:** phone icon se khulne wale page ka naam ab **Mobile Style** (header me likha aata hai).
2. **Number se size:** Edit me Width / Height / Btn W / Btn H ke slider ke saamne ab number box hai - slider bhi chalega, number type karke Enter dabao to bhi size set ho jata hai.
3. **Ek button kai baar:** palette se same button 3, 4 ... (max 40) baar add kar sakte ho. Palette me "x3" jaisa count dikhta hai.
4. **Phone jaisa gesture - sirf pad ke andar:** pad ke neeche ke edge se upar swipe = **Home**; upar swipe karke ungli rok do = **Recent**; pad ke left/right edge se andar swipe = **Back**. Pad ke bahar ka screen ab koi gesture nahi leta.
5. **Naye add-able controls (Edit me palette se):** Scroll up/down bar, Scroll left/right bar, Volume bar (upar-neeche), Volume bar (left-right), Nav bar (arrows + OK), extra Touchpad. Har ek ka size slider / number / corner handle se badal sakte ho.

Files: app/assets/remote.html, tests/test_mobile_style.py (13 checks), tests/test_trackpad_page.py (32 checks).

# Remote70 Kb
- Bluetooth Remote Panel ab dedicated Bluetooth layout hai: har button + trackpad sirf Bluetooth HID se jaata hai (Wi-Fi / TV protocol use nahi hota).
- Default layout me saare buttons: Back, Home, Mute, Vol -, Vol +, Mic, Keyboard, Menu, Recent, Search, Play, Settings (Edit me aur bhi add ho sakte hain).
- Trackpad ab NORMAL remote trackpad hai (mouse mode nahi): swipe = arrow keys (pehla step 42px, phir har 72px, ungli rakho = repeat), tap = OK / Enter. Extra "Touchpad" widget bhi same.
- Layout ka saved key badla (remote70_btp_layout) taaki naya default ek baar apply ho. Reset = naya default.
- Test: tests/test_bt_dedicated.py (14 checks).
